# corpMind 工程文档

文档版本：v0.2-draft。更新日期：2026-10-26。状态：初稿待评审；不代表产品已实现。

## 1. 项目基线

- 产品方向：企业售后问题调查与处理 Agent。
- 首版闭环：订单与物流调查 → 政策核对 → 形成方案 → 人工确认 → 创建本地工单。
- 数据条件：单一虚构企业、两个业务组、本地模拟业务数据与政策。
- 开发安排：Python 为主，先后端再前端，预计8～12周，每周10～15小时。
- 当前阶段：需求评审与技术验证准备。业务实现、用例执行、评测及发布均未完成。

## 3. 文档与变更规则

1. 业务行为以需求规格为基线，接口和实现必须可追溯到需求编号。
2. 设计初稿经验证后更新为评审通过；实现偏离基线时，先记录变更影响并同步文档、测试。
3. 使用“计划、已实现、已验证”区分状态。通过状态必须附提交、测试输出或实际操作记录。
4. 不在文档中填写密钥、真实客户信息、伪造实验结果或未验证的性能数字。
5. 每个里程碑提交一个可独立审查的变更，范围和验证方法写入 Pull Request。
6. 新增 SDK、模型或基础设施前，确认当前官方文档、兼容性及成本；记录实际锁定版本。
