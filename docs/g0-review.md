## 2. 已确认的主流程与边界

1. 明确本次调查的唯一订单；缺少或歧义时追问，保留当前任务，不查询无关对象。
2. 查询订单、物流和适用政策，必要时检索授权历史案例；分别记录客户陈述、业务事实及政策证据。
3. 代收尚未核实时等待核实；补充已核实仍未找到后，在关键证据齐全且无冲突的条件下形成方案。客户反馈已找回时展示该陈述并完成任务，零工单。
4. 运输中严格超过预计送达时间48小时，才具备延迟调查方案资格；尚未到期或超时不超过48小时（含恰好48小时）时，证据齐全则展示结果并完成调查，零工单。时间取自查询服务。
5. 形成方案后等待当前登录客服点击“确认创建”；补充核实结果、普通聊天、暂缓、否定和取消均不构成确认。
6. 暂缓时保留方案并等待；否定时旧方案不可确认，追问并修订；明确取消调查时结束任务。以上分支均不创建工单，已提交的工单不能被取消操作伪装成撤销。
7. 首次创建前核验身份、归属、权限和当前方案及证据版本。过期或证据不足时拒绝创建；同一成功方案重复确认返回已有工单，不再次执行写入。任务恢复先核对真实结果，不盲目重放写操作。

固定运输时间边界的预期时长为-1秒、0秒、1秒、47小时59分59秒、48小时、48小时1秒；前五个分支completed且零工单，最后一个在证据充分时awaiting_confirmation，按钮确认成功后completed且仅一条工单。具体固定记录见测试计划。
