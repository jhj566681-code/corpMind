# corpMind 测试与评测计划

版本：v0.2-draft。日期：2026-10-26。状态：测试设计初稿；尚无可执行测试、80条数据集或测试结果。

## 1. 测试范围与方法

- 单元：业务规则、时间计算、参数、授权、索引、引用、状态转换和幂等。
- 契约：API与工具输入输出、错误代码、模型适配器、MCP与进程内工具一致性。
- 集成：临时SQLite、固定业务记录、模拟模型与故障注入；覆盖完整调查和确认写入。
- 端到端：使用客服和管理员账号，在界面完成导入、调查、确认、查看及取消。
- 效果评测：固定资料、时钟、模型、提示词及方案，核对事实、引用、工具行为与最终业务状态。

每个自动测试独立建临时数据并清理；不使用开发者真实资料，不需要云端密钥。付费模型的烟雾测试单独启用，记录次数与用量。

## 5. 对比实验与指标

方案A：基础RAG；方案B：固定工具流程；方案C：有限轮次ReAct Agent。分别评测共同的知识问答子集，以及适用于B/C的闭环业务任务；A缺少实时工具时应正确说明不足，不要求其编造订单事实。

固定资料和业务快照、权限、模型、提示词版本和调用上限。报告每种方案的实际用量和耗时，而不是假设成本相同。模拟服务结果与真实模型结果分开报告。

| 指标 | 定义或目标 |
| --- | --- |
| 任务成功率 | 事实、适用政策、结束状态及副作用均符合参考判定；首版目标≥80% |
| 检索Recall@5 | 在已标注的政策问答子集统计相关证据召回；初始目标≥80% |
| 引用有效性 | ID、版本、原文位置和引用文字可核对；程序检查目标100% |
| 证据支持率 | 人工核对关键结论是否被所引证据支持；初始目标≥90% |
| 未授权泄露与未确认写入 | 固定安全测试目标为0，任何失败阻断发布 |
| 幂等与恢复 | 相关测试全部通过，重复和中断不增加错误工单 |
| 耗时与费用 | 记录P50、P95、调用次数、token、已知估算及未知项；无实测前不承诺数值 |

这些是验收目标，当前无通过结果。冻结集未达质量目标时记录失败分析，继续改进或缩小发布范围，不伪称达标。
